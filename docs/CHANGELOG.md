# Changelog

## [2026-08-13]
### Added
- Created `IMR.md` containing a complete Entity-Relationship Diagram (ERD) using Mermaid.js syntax. 
- This document was generated by directly introspecting the live cloud database (Aiven MySQL) to accurately map all tables, columns, data types, primary keys, and foreign key relationships.
- The ERD uses standard Crow's Foot notation to illustrate relationships like `1-to-many` between entities (e.g., `User`, `Bookings`, `Tours`, etc.).

### Added
- Created `UseCase_MakeBooking.md` detailing the "Make Booking" use case narrative. 
- This document outlines the step-by-step basic flow, preconditions, postconditions, and alternative flows (like insufficient capacity or invalid input) when a user attempts to book a tour.
- Created `DomainModel.md` containing the high-level, conceptual UML class diagram (using Mermaid.js syntax).
- The diagram focuses on business domain entities (User, Profile, Admin, Tour, Booking, CuratedSpot, etc.) and their semantic relationships, grouping them into logical namespaces (`UserManagement`, `SocialAndCommunication`, `ToursAndBookings`, `LocationsAndSpots`).
- This was added to provide a clear, visual understanding of the system's data relationships without cluttering it with technical implementation details (like primary keys or methods), helping in future architecture planning.
